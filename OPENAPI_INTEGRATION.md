# Mobile SDK integration using OpenAPI

This project includes **OpenAPI 3.0.3** definitions for the Go API's implemented endpoints. The published contract is the same in YAML and JSON.

| Endpoint | Use |
| --- | --- |
| `GET /docs` | Interactive Swagger UI; its UI files load over the internet from jsDelivr |
| `GET /openapi.yaml` | Human-readable OpenAPI schema |
| `GET /openapi.json` | OpenAPI schema for client generators |

These endpoints are available after starting the Go server with `docker compose up --build -d` (live mode, port 8080), `docker compose -f compose.demo.yaml up --build -d` (demo, port 8081), or `go run . ...`; the schema files are also available for local generation without a running server. Windows PowerShell setup is documented in [WINDOWS_DOCKER.md](WINDOWS_DOCKER.md).

## Generate a typed API client

Examples use [OpenAPI Generator CLI](https://openapi-generator.tech/docs/installation/). Node.js/npm is needed for the `npx` commands. Run in the extracted `grocery-api/` directory:

```bash
# Flutter / Dart
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json -g dart -o clients/dart

# Android Kotlin (OkHttp)
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json -g kotlin -o clients/kotlin

# iOS Swift
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json -g swift5 -o clients/swift

# React Native / TypeScript (fetch)
npx @openapitools/openapi-generator-cli generate \
  -i openapi.json -g typescript-fetch -o clients/typescript
```

Set the generated SDK's **base URL** to your deployed `https://...` API (not `localhost` when running on a physical mobile device). Import/install the generated SDK as directed by OpenAPI Generator. Exact function/class names can differ with generator version; generated operation IDs include `listProducts`, `compareOffers`, `quoteBasket`, `createBasket`, and `quoteSavedBasket`.

## Example: cheapest basket (stateless)

```http
POST /v1/basket/quote HTTP/1.1
Content-Type: application/json

{
  "items": [
    {"comparison_key":"milk|unspecified|uht|3.2|plain|normal","amount":2000,"unit":"ml"},
    {"comparison_key":"bread|white","amount":500,"unit":"g"}
  ],
  "allow_candidate_matches":true,
  "max_stores":2,
  "max_age_hours":168
}
```

This response includes `cheapest_single_store`, `cheapest_split_basket`, `store_options`, `warnings`, and optionally `savings_minor`. **Never display `partial_total_minor` as a complete basket total.** If `complete=false`, `total_minor` and `total_mkd` are `null`. All `*_minor` values are in 1/100 MKD; `*_mkd` are decimal MKD for presentation. The mobile app should display the freshness/availability and *unverified candidate* flags.

## Saved baskets and authentication

1. `POST /v1/auth/register` or `POST /v1/auth/login` — returns an opaque seven-day `access_token` (user session).
2. Store it in Android Keystore / iOS Keychain, not logs or analytics. Send `Authorization: Bearer <access_token>` for `GET /v1/auth/me`, `GET /v1/me/baskets`, and account-owned basket CRUD.
3. `POST /v1/baskets` **with** that bearer token creates an account-owned basket; no basket secret is needed.
4. Existing anonymous `POST /v1/baskets` (without bearer token) still returns a one-time `basket_token`. Legacy basket operations use `X-Basket-Token`; use `POST /v1/baskets/{id}/claim` with **both** auth headers to transfer ownership.
5. `POST /v1/auth/logout` revokes the current user session. `POST /v1/admin/sync` uses a completely separate administrator bearer credential (the `ADMIN_TOKEN` environment variable).

OpenAPI 3.0.3 defines `UserBearer`, `BasketToken`, and `AdminBearer`, including the account/legacy alternatives and the combined claim requirements. Public catalog, search, comparison and stateless quote endpoints remain unauthenticated. Account passwords use a salted PBKDF2-HMAC-SHA256 verifier and sessions are revocable; see `AUTH_AND_CRAWLERS.md` for production security limitations.

## Current limitations

- Comparison keys are generated by deterministic classification rules, not proof that items are identical. Only opt into `allow_candidate_matches=true` when users accept approximate substitute suggestions.
- Retailer crawlers still need live integration validation. Vero/Jumbo now have a paginated price-table crawler; Kipper and BigShop have experimental online priced-listing crawlers; KAM and Stokomak still rely on CSV feeds. Prices may be stale or incomplete.
- Locations, delivery fees, travel distance, stock quantity and price validity intervals are not included. User accounts and in-memory login throttling have been implemented, but production-grade distributed anti-abuse controls and email verification remain outstanding.
- Swagger UI loads JS/CSS from a CDN. Downloaded OpenAPI YAML/JSON and generated clients are independent of the CDN.

## Maintain the contract

The specification is versioned with the Go handlers. After changing routes or DTOs, edit `scripts/generate_openapi.py` and run:

```bash
python3 -m pip install PyYAML
make openapi
CGO_ENABLED=1 go test ./... -count=1
```

The `openapi_contract_test.go` checks each documented method/path against the Go router; tests do not replace verifying fields and response status codes when you add future endpoints.
